# Step Back Club

NBA charts at [billmill.org/nba](https://billmill.org/nba). Every chart is a
tool: pick a season or a team, annotate it, and export it as an image.

Built with [Astro](https://astro.build) and D3, reading
[nba_data](https://github.com/llimllib/nba_data)'s parquet files in the
browser.

```
npm install
npm run dev
```

See `AGENTS.md` for how it's put together, and `docs/plans/` for why.
